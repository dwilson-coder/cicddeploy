## Overview

CICD Deploy is a React-powered reference guide for comparing deployment platforms and following a repeatable path from repository to production. It includes platform notes, deployment commands, environment variable guidance, configuration starters, and a GitHub Actions example.

## Included Platforms

- Netlify
- Vercel
- Cloudflare Pages
- Render
- Firebase Hosting
- Surge

Search results link directly to each platform's official documentation.

## Run Locally

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
